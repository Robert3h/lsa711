SW711 TECH LOG // 星羽號維修日誌

這個網站是怎麼設計的

首航以來，這艘船進廠改裝過很多次。每一次，都在回答同樣三件事。

  1. 初衷 01好讀讀起來不費力
  2. 初衷 02好找想讀的那篇找得到
  3. 初衷 03有樂趣，但不堆砌、不轟炸好玩是加分，不是干擾

初衷 01 好讀

讀起來不費力：知道讀到哪、看得出重點、橫圖轉得過來。

  • MX-1113-10 · 2026-11-13

    幻燈片：下一張露出一截

    讀者遇到什麼
    每組幻燈片下面都有一段「手機可以左右滑」，要先讀說明，才知道怎麼用。
    ○ 選擇這樣做
    讓介面自己說話：每張不佔滿整排，右邊露出下一張的邊，看到就知道可以往右滑。
    ✕ 選擇不做
    拿掉 22 頁的操作說明。需要寫說明，代表介面還不夠清楚。

    「最好的 UI 是不需要說明」

    作者畫的重點，讀者看得出來

    讀者遇到什麼
    在 Word 裡加粗、上色的金句，到了網站和一般句子長得一樣。
    ○ 選擇這樣做
    照 Word 搬上網站，但重點字改用青色：橘色在全站代表「可以點」，重點不能讓人誤以為是連結。
    ✕ 選擇不做
    整篇都加粗的 3 篇不套：全部都是重點，就等於沒有重點。

  • MX-1114-06 · 2026-11-14

    深色模式，卡片也看得出邊

    讀者遇到什麼
    深色模式下，卡片和背景幾乎一樣黑，看不出一張卡從哪裡開始、到哪裡結束。
    ○ 選擇這樣做
    只把深色的框線調亮一階：看得出邊界，但不搶內容。淺色本來就清楚，不動。
    ✕ 選擇不做
    不拉到最高對比：每張卡都描上粗框，畫面就變成線框圖。

    「黑色的卡片，邊界沒有像白色這麼明顯」

初衷 02 好找

想讀的那篇找得到：第一次來有起點，說一句話就推薦。

  • MX-1106-01 · 2026-11-06

    第一次來，從這三篇開始

    讀者遇到什麼
    第一次來的人，面對幾十篇文章，不知道從哪一篇讀起。
    ○ 選擇這樣做
    首頁直接推薦三篇：一個工作案例、一篇文章、一段角色對話，三種內容各挑一篇。
    ✕ 選擇不做
    不挑最新的，挑沒有前情也讀得懂的。
    看首頁的三篇 →

  • MX-1022-08 · 2026-10-22

    全部傳訊：一頁看完所有航線

    讀者遇到什麼
    文章散在 LinkedIn、Vocus、Substack，想找一篇要翻好幾個平台。
    ○ 選擇這樣做
    一頁列出所有已發布的傳訊，依月份排，可以只看生活隨筆、電子報或小劇場；能在本站讀的，直接點開。
    ✕ 選擇不做
    草稿和私人筆記不列：Word 目錄有日期的，才算發布。

  • MX-1107-08 · 2026-11-07

    找 3 篇：說一句話，推薦三篇

    讀者遇到什麼
    不知道哪一篇和自己有關，只能從標題猜。
    ○ 選擇這樣做
    打一句最近卡住的事，網站依文字相似度推薦 3 篇；找不到很接近的，就列出每篇文章的「情境」讓讀者自己挑。
    ✕ 選擇不做
    打的字不送出、不記錄，只在讀者自己的瀏覽器裡比對。
    試試找 3 篇 →

  • MX-1114-07 · 2026-11-14

    工作之外：先給結論，再給文章

    讀者遇到什麼
    來看工作經歷的人，不知道寫作系統和自己有什麼關係，也不會特地點過去。
    ○ 選擇這樣做
    工作頁最下面精選 3 篇：日期旁標主題，底下一句說為什麼值得讀。先給結論，要不要點由讀者決定。
    ✕ 選擇不做
    不在頁面上方放大橫幅，也不把最新文章搬過來：工作頁的主角是報表成果。

    「先結論再推論，滿符合專業人的需求」

    音樂和影片，按了才開始

    讀者遇到什麼
    打開網頁突然冒出音樂，或是手機在背景偷偷下載影片。
    ○ 選擇這樣做
    設定集頁右下角滑出一張小卡，讀者自己選［▶ 播放］或［■ 不用了］；影片按了播放才下載。選擇只記在讀者自己的瀏覽器。

    不自動播放；卡片說有音樂，就一定真的有音樂。

初衷之外 對文章裡的人

  • MX-1112-06 · 2026-11-12

    文章裡的真實人物，名字不跟著上站

    讀者遇到什麼
    有些文章寫到真實的主辦人、講者和家人，他們沒有同意被寫進網站。
    ○ 選擇這樣做
    真名換成 A君～D君，家人只寫稱謂；原稿裡找不到要遮的字，程式就停下來，不會漏遮還照樣上線。
    ✕ 選擇不做
    還不確定能不能公開的，先暫緩，不先上再說。

    「公司名稱碼掉、講者用 A君 這類代號、可以上的先上」
